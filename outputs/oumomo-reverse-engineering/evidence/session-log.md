## 关键失败签名

```text
链接生视频：Unexpected token '<', "<!DOCTYPE "... is not valid JSON
复刻上传：fileChooser.setFiles Not allowed
```

`复刻上传` 失败签名在开启 Chrome 扩展 `Allow access to file URLs` 后消失；它是本机工具权限问题，不是 Oumomo 业务失败。
