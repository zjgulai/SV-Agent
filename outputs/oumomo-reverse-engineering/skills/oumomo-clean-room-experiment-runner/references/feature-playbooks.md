Re-read live quotes and capabilities on every run; previous observations are evidence snapshots, not current pricing guarantees.

## Script generation

Freeze product fixture, fact list/order, duration, type/pattern, language, audience and promotion. Establish 2–3 identical baselines before changing one field.

Extract typed phases/shots, titles/tags and every claim. Test:

- duration → phase/shot budget;
- pattern → rhetoric and unsupported-claim rate;
- language → localization vs structural rewrite;
- audience → scene adaptation vs invented persona facts;
- fact order/delete → priority and negative-constraint adherence;
- promotion → exact verified offer vs expansion.

A UI delete is not a negative constraint unless the deleted fact is absent from every output field.

## URL-to-video and replica

Record parsed facts/images before generation. Freeze type, language, model/mode, resolution, duration and count. Submit one failure-regression baseline before any matrix.

After submission:

- Treat frontend parse errors as ambiguous.
- Recover through Job queue/project using the existing operation.
- Inspect the compiled prompt and output separately.
- Audit invented packaging, numeric claims, efficacy, transformations and reactions.
- Download only authorized output; discard raw signed URLs after hashing.

Stop the matrix after an ambiguous paid boundary even when the original task later succeeds; the goal is to prevent duplicated spend.

## Templates and image models

Template comparison requires stable template identity/version, same product inputs, same model and at least 2 repeats per template. Hidden-until-upload quotes block the matrix unless upload is authorized and the pre-submit total is visible.

Model comparison requires identical reference bytes, prompt, ratio, resolution and count. Measure packaging text, color/Logo, product geometry, hands/people, scene adherence and within-model variance. Sniff downloaded bytes instead of trusting the extension or response Content-Type, and treat a missing real package mark as a failure even when whole-frame repeat similarity is high.

## Avatar and video-model routing

Use only site-provided authorized avatars unless the user separately authorizes likeness/voice assets. Record avatar version, voice, background, duration, resolution and quote.

Treat a named model as a model and labels such as Mini/fast/quality as modes. Cross-model causality requires concrete model names and identical inputs. Stop when a per-run or matrix cap is exceeded.

## Quality score and deduplication

Calibrate quality scoring with controlled variants from one source: original, compression, wrong ratio, muted, audio offset and key-visual obstruction. Require repeated identical-file scores and dimension-specific sensitivity.

Do not claim deduplication from naturally different generations. Require a source/transformed pair and compare perceptual media, shot structure, ASR/OCR, audio and fact preservation.

If selecting a project changes to an unrelated route, record a routing defect and zero-debit blocked result.

## Publication dry-run

Inspect video, cover, account, title, tags, product, product name, precheck, AI disclosure, privacy and scheduling fields. Selecting an existing project is allowed only before external authorization.

Stop before:

- OAuth or QR authorization;
- account/product binding;
- scheduling confirmation;
- final publish action.

Do not repeat vendor claims about weighting, reach or distribution as measured outcomes. Real publication needs explicit authority and an external receipt.
