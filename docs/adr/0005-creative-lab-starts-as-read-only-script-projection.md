# Creative Lab 首期采用现有 Script identity 的只读 Projection

Variant C 已被选为产品方向，但首期不创建 Creative Lab、Experiment 或 Decision 的新持久化 identity，也不把 Leap、Oumomo 或 Momcozy 素材目录接成在线 runtime dependency。Creative Comparison Lab 通过一个 deep application Module，在现有 Script compare route 上组合两个不可变 Script Version、当前 Product Fact Gate、validation 与 Storyboard readiness；外部证据只返回有界 availability 和引用。这样牺牲了可保存实验与通用查询的灵活性，换取零 migration、可回滚、无跨域事实合并，并避免在 tenant/auth、single-variable compiler 和 Decision authority 未获批前把 UI 选择误写为生产工作流。
