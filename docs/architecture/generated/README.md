# Generated Architecture Artifacts

The authoritative generated graph is stored at [`.ua/knowledge-graph.json`](../../../.ua/knowledge-graph.json), with the structural baseline in [`.ua/fingerprints.json`](../../../.ua/fingerprints.json) and freshness metadata in [`.ua/meta.json`](../../../.ua/meta.json).

The graph is regenerated after module, dependency, path or long-lived documentation changes. It is accepted only when the final reviewer reports zero critical issues, all file-level nodes belong to exactly one layer, and every layer/tour reference resolves.

Do not copy the graph into this directory. This page is a stable documentation route; `.ua/` remains the single generated artifact location.
