# Content Performance Intelligence

定义外部平台表现、视频方向和创意信号如何进入 Momcozy 洞察故事线。这个上下文记录观察和假设，不把相关性、AI 摘要或外部卖点升级为商品事实。

## Language

**Performance Window**:
一次内容表现观察明确覆盖的品牌、产品、平台和时间范围。
_Avoid_: Current performance, latest data

**Performance Observation**:
在 Performance Window 内由外部报告直接显示的计数、汇总或排名；缺失值必须与零分开。
_Avoid_: KPI truth, business fact

**Platform Breakdown**:
同一 Performance Window 按平台拆分的账号、视频和互动观察。
_Avoid_: Channel benchmark

**Content Direction**:
外部报告对视频表达方式的命名和归类，是待验证的创意候选而不是 FactFrame Creative Pattern。
_Avoid_: Winning formula, approved pattern

**Creative Signal**:
内容表达与观察到的表现之间值得继续验证的关联；它不证明因果关系。
_Avoid_: Growth driver, causal insight

**Reported Product Claim**:
外部分析归纳出的产品卖点，尚未通过 Product Fact 状态和来源证据验证。
_Avoid_: Product Fact, confirmed claim

**Evidence Disposition**:
对外部观察作出的 `cite`、`recompute`、`test` 或 `reject` 决定。
_Avoid_: Approval, import status

**Hypothesis Reference**:
把一个 Creative Signal 连同 Performance Window、来源和 digest 绑定到 Creative Comparison Contract 的不可变引用；它解释假设来源，不证明效果。
_Avoid_: Performance proof, winning signal

**Observation Availability**:
一个 Performance Observation 的值语义，明确区分 observed value、observed zero、not reported、not collected、not applicable、redacted 和 unresolved。
_Avoid_: Null, dash, missing value

**Performance Subject Binding**:
对 Performance Window 的 subject 与 Product Family、Model、Variant 或确切 Product Snapshot 是否匹配的审核结论；相同 Brand Workspace 本身不构成匹配。
_Avoid_: Brand match, fuzzy product join

**Reviewed Performance Package**:
带不可变 digest、范围、来源、Observation Availability、Evidence Disposition 和方法限制的机器可读 Performance 投影。
_Avoid_: Imported Product Facts, report dump
