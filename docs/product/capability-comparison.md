# Capability Comparison

## Comparison rule

The four columns are different kinds of subjects. FactFrame is a running product system, Oumomo is a clean-room observed provider, Momcozy is a brand asset workspace, and Leap is a verified but method-limited external performance report. A blank or `Unknown` is preserved rather than scored as zero.

| Dimension | FactFrame | Oumomo evidence | Momcozy workspace | Leap report |
|---|---|---|---|---|
| Primary role | Evidence-first script and storyboard platform | External capability experiment subject | Main brand and local commercial asset case | External insight/reporting reference |
| Fact authority | PostgreSQL Product Snapshot/Fact | Experiment manifests and observations | Public product source + local provenance/QA | Dated external observations; never Product Facts |
| Immutability | DB-enforced snapshots, generations, versions and events | Append-only ledgers and hash-bound artifacts | One-asset bundles with hashes; archive rejects overwrite | Public report has no disclosed snapshot/ingestion timestamp |
| Claim governance | confirmed/locked allow-list and excluded deny-set | Detects provider hallucination; does not create product facts | QA blocks unreviewed generated claims | Core selling points are AI-derived and require FactFrame allow/deny mapping |
| Execution reliability | Idempotent Job, outbox, lease/dead-letter and fencing | Records observed remote state and credit continuity | Local archive/validator, no remote execution service | Getter payload verified; upstream collection/retry path undisclosed |
| Creative structure | Versioned Pattern Definition and server-owned copy | Observes provider templates/models under frozen configs | Concept groups, prompts and channel intent | Content Direction plus bilingual Hook/Clip/CTA, voice-over, scene and technique decomposition |
| Validation | Deterministic script and storyboard gates | Evidence validator + media probes/scorecards | Bundle contract, sensitive scan and per-file QA | Output shows language, unrelated-text, unit and completeness defects; no disclosed validator |
| Cost evidence | ProviderRun/cost ledger not yet implemented | Quote and Credit Ledger | Per-asset Recipe and batch reconciliation | No cost data |
| Asset provenance | Storyboard has no media asset | Local artifact hashes | Asset Bundle Provenance + hashes | Video rows and metrics are visible; source/collection provenance undisclosed |
| Approval boundary | Local Storyboard Approval; no render/publish | Technical/factual verdicts only | `hold`, `revision-needed`, internal selection, brand approval | Ranking and AI analysis are hypothesis evidence only |
| Insight presentation | Capability docs and graph | Findings/reports/SOP | Whole-workspace Aggregate Index plus scoped batch reports | Cross-platform KPI, follower, trend, Top 10 and video-asset views |
| Production publication | Out of scope | Not proved | Prohibited without exact brand review | Edit/generate actions are visible but were not called or accepted as capability |

## Evaluation

- **Strongest integrated control:** FactFrame, because facts, execution, validation and immutable versions form one database-backed chain.
- **Strongest experimental audit:** Oumomo evidence, because configuration, state, cost and artifacts can be cross-checked without treating provider UI as truth.
- **Strongest concrete brand asset base:** Momcozy, because 244 bundles carry local provenance and QA and now reconcile through one Aggregate Index. Its remaining gap is metadata/Commercial Approval coverage and private automation, not raw asset count.
- **Strongest observation and decomposition surface:** Leap, because one public workspace combines exact multi-platform aggregates, trend series, ranked videos and structured creative analysis. Its method and generated analysis remain weaker evidence than FactFrame or Oumomo contracts.

The composite solution therefore uses Leap for bounded observation and video decomposition, FactFrame for truth and workflow control, Oumomo for controlled empirical validation, and Momcozy for the primary asset and decision case.
