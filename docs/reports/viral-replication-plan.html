决策：采用方案 A。canonical skills 放在 .agents/skills/ 以保持 Codex 可发现与单一权威；每个 workflow 文件夹只维护一个 SOP.md 与 skill-map.md，不复制 skill 实现。
证明边界：当前项目已经具备 Product Truth、脚本/分镜、实验和可靠执行骨架，但没有因此获得 RenderJob、视频生成、账号、billing、社交发布或 production acceptance。本方案先沉淀 agent 能力和可验证工作流，不把设计写成 runtime。

1. 当前项目能力与缺口

已存在的深模块

Product Source/Snapshot/Fact、Creative Pattern、Script Version、Storyboard、Job/Outbox/Celery fencing、Creative Comparison、Experiment Evidence、Momcozy Asset Intelligence、Readiness。

可复用的事实边界

PostgreSQL 是业务事实源；参考内容、外部表现、实验和素材保持 typed evidence plane 分离；只有 confirmed/locked Fact 支持商品声明。

已暴露的复刻风险

参考不稳定、n=1、技术成功但内容失败、模型扩写功效/包装/促销、删除事实后重新出现，以及多变量漂移。

当前缺口

ReferenceBundle、机制抽象、复刻合同与复刻结果版本化仍只到文档/agent 能力层；Media Integrity 已定义验收门，但尚未实施真实 ASR/OCR、镜头归一化、媒体生成、版权/商业批准或发布。

权威入口：docs/index.md、系统架构、项目级 Skill 系统、执行台账。

3. 方案 A 的物理结构

.agents/
├── skills/                         # canonical、可发现、单一权威
│   ├── factframe-*/                 # 既有 FactFrame skills
│   └── viral-*/                     # 复刻窄 skills
└── workflows/viral-replication/     # 编排与 SOP
    ├── README.md
    ├── routing-decision-tree.md
    ├── shared-artifact-contracts.md
    ├── shared-scorecard.md
    └── <workflow>/
        ├── SOP.md
        └── skill-map.md

这个结构在“可发现性”和“局部性”之间取平衡：skill 保持 deep module，小 interface 隐藏复杂判断；SOP 只负责编排、停止条件、completion criteria 和 handoff。workflow 不复制 skill，避免安全规则漂移。

6. 首批三个 Workflow SOP

01 Narrative Transformation

intake → decomposition → abstraction → narrative adapter → fact mapping → script/storyboard → contract → media-integrity → evaluation → readiness

阻断：叙事必须依赖未确认功效、第二变量漂移、复制原始台词或目标商品事实不足。

02 Proof Demonstration

intake → proof decomposition → proof adapter → fact mapping → proof storyboard → contract → media-integrity → evaluation

阻断：物理类比越权成效能证明、数字/单位缺证据、n=1 却要求因果结论。

03 Experience POV

intake → POV decomposition → experience adapter → fact mapping → storyboard → contract → media-integrity → evaluation

阻断：体验语言暗示功效、商品 identity 跨镜头变化、音频/素材授权不明。

04 Attention Grammar

intake → timed attention map → abstraction → attention adapter → fact mapping → storyboard → single-component contract → media-integrity → evaluation

阻断：表层复制、趋势音频误路由、多个 attention component/时长/声音漂移，以及把结构写成留存或播放因果。

05 Conversion Action

intake → conversion map → abstraction → conversion adapter → Product Truth → fact mapping → storyboard → single-component contract → media-integrity → evaluation

阻断：Promotion 进入普通 Facts/provider、数据库时间失效、非最终 CTA slot、未绑定外链/下单，以及仅因有 CTA 而误路由。

06 Trend Native

intake → trend map → abstraction → trend adapter → Product Truth → fact mapping → storyboard → single-component contract → media-integrity → evaluation

MECE 组件：趋势信号、共享语境、模板结构、音频功能；TrendAdmissionRecord 把来源观察/替换输入交给 Media Integrity Gate。阻断：趋势表层误路由、未有界的当前热度、来源音频/模板复用、平台兼容/上传/发布越权。

07 Media Integrity Gate

frozen contract + fact-bound storyboard → traceability / technical / surface / identity / source-use / originality → finding → readiness

横切而非第七主类型。每道 gate 独立有证据和 blocker；preflight 的 artifact 项只能是 pending，任何 QA、资产索引或模型审阅均不等于版权、商业、平台或发布许可。
