结论先行

当前项目已经具备外部内容表现观察、强事实治理、可靠异步执行、脚本/Storyboard 审核和本地实验/素材证据能力。关键不是把数据放在一起，而是让每个信号经过正确的事实、实验和审批边界。

推荐方案：保持 Leap 表现信号、PostgreSQL 业务事实、Oumomo 实验证据和 Momcozy 素材证据物理隔离；首个产品化形态选为 Creative Comparison Lab 内的只读 Decision Brief，通过独立 reviewed binding registry、typed evidence sections 和 Fact Gate 形成可复核融合。暂不建设独立 Insight Hub。

四个证据上下文，一个决策模型

BUSINESS TRUTH

Product Truth & Script

Product Snapshot/Fact、Script Generation/Version、Job/Outbox、Validation 与 Storyboard 由 PostgreSQL 维护。它回答“可以说什么、是否真实完成、为什么可接受”。

EXPERIMENT EVIDENCE

Oumomo clean-room

Manifest、state events、Credit Ledger、artifact hash 和 Scorecard 回答“外部能力在冻结条件下实际表现如何”。结论有范围，不升级成商品事实。

ASSET EVIDENCE

Momcozy Asset Intelligence

Asset Bundle、Recipe、Provenance、QA 与 hash 回答“哪个素材可复用、需返工或仍应 hold”。结构有效不等于商业批准。

PERFORMANCE SIGNAL

Leap Content Intelligence

Performance Window、平台拆分、累计趋势和 Top 10 Content Direction 回答“哪个信号值得继续测试”。排名和 AI 卖点不成为 Product Fact。

Momcozy 洞察故事线

每一步都产生下一步可验证的输入。外部排名先变成 Creative Signal，Reported Product Claim 必须通过 confirmed/locked fact 门禁。

01 捕捉表现冻结品牌、产品、平台、时间窗和缺失值。
02 解构视频把方向、Hook/Clip/CTA 和视觉手法标为 AI hypothesis。
03 建立真相Snapshot 与 Fact allow/deny contract。
04 编译假设Pattern、受众、促销位和 shot topology。
05 执行验证Job timeline、provider boundary、blocking findings。
06 审核分镜零成本 typed preview 与 live fact recheck。
07 学习决策实验/素材反馈，选择 ship、revise、collect 或 stop。

Aggregate Index

P1 LOCAL

Private validation gate

已将公开 synthetic CI 与真实库只读验证物理隔离；projection-digest-bound 基线、双编译和 descriptor-bound canonical current release 校验形成有界 Gate Receipt，但不等于商业批准或生产验收。

P1 LOCAL

Port dependency

已把 ParsedProduct 归属移至 ProductConnector port；adapter 单向实现该 Interface，架构测试持续拒绝 port → adapter 导入，HTTP、解析与持久化行为不变。

P1 DESIGN

Insight Decision Brief

compare-bound Interface、typed sections、provenance、UX 和 rollback 已闭合；contract/package/runtime 尚未实现，standalone Hub 延后。

P1 DESIGN

Performance package

推荐执行顺序

关闭 Leap evidence mapping

保留 2026-08-21 至 2026-08-27 的精确观察、结构化解构、质量缺陷和方法边界。

关闭 Aggregate Index 本地验收

以 validator、ledger、scoped index 与 frozen plan 对账 244 Bundle；相同输入保持 current manifest 与不可变 JSON/Markdown release byte-identical，blocked/失败构建不切换 current。

持续运行私有资产门

本地只读 automation 调用同一 Private Gate；公开 CI 只跑 synthetic fixtures，商业批准继续逐文件人工完成。

保持依赖方向闭合

Shared type 已迁至 port；继续用架构测试和 connector 行为测试防止反向依赖回归。

关闭 Decision Brief 设计

产品价值、compare-bound Interface、主体绑定、缺失值、provenance、权限、UX 与 rollback 已形成完整合同；runtime 仍为空。

下一门：只实现 package contract

单独批准 context-specific models、validator 与 Synthetic Fixtures；不连接 filesystem、Web、外部网络或私有 evidence。

再评估 public Performance pilot

只有 public reviewed package 通过 Snapshot id + recomputed digest + evidence context composite binding 后，才用 default-off Adapter 接入 comparison；M5 私有证据继续隔离。

最后才编译 Signal-to-Experiment

先批准 append-only comparison contract、canonical subject ownership 与 single-variable compiler，再生成 Hook Variant。
