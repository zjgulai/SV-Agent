# 网站人话表达优化方案

## 目标

把工作台的专业信息改成业务、创意和工程人员都能快速读懂的表达。

每个模块按同一顺序说明：

1. 先说结论：这个模块帮用户做什么决定。
2. 再说依据：我们知道什么，还缺什么。
3. 最后说行动：下一步做什么，什么情况下必须停。

本轮只改表达。页面结构、交互、数值、状态码、案例事实、证据边界和下载合同都不变。

## 写作规则

### 1. `humanizer-zh`

- 删除套话、宏大判断和营销式修饰。
- 不用“不是……而是……”制造假反转。
- 不把三个近义词排在一起制造完整感。
- 用具体的人、动作、对象和结果代替抽象名词。
- 长短句交替，但一句只讲一个判断。

### 2. ASD-STE100 启发式规则

ASD-STE100 是英文技术写作标准。本网站是中文界面，因此只采用它的清晰写作原则，不宣称正式合规。

- 同一个概念只用一个名称。
- 一句话只讲一件事。
- 优先使用主动句。
- 操作说明以动作开头。
- 条件会影响操作时，先写条件，再写动作。
- 状态码和技术名词原样保留，并在前面补中文解释。

参考：[ASD-STE100 Issue 9](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) 和 [ASD-STE100 FAQ](https://www.asd-ste100.org/STE_faq.html)。

### 3. 咨询公司金字塔表达

- 首屏：先给结论，再给限制。
- 模块标题：直接说明用户能完成什么。
- 卡片正文：先写判断，再写证据和替代解释。
- 流程说明：先写动作，再写产物，最后写停止条件。
- 决策页：先给当前决定，再说明为什么不是发布批准。

## 页面改写范围

### 工作台首页 `dist/index.html`

- 导航和首屏：从内部术语改成用户动作。
- 复刻工作台：把“路由”解释为“只选一个主机制”。
- 融合方案：说明来源、证据和复刻合同如何连接。
- 案例：每个案例先说结论，再说证据限制。
- 技能：先说明“什么时候用、得到什么、什么时候停”。
- 工作流：先说明适用场景，再给最小步骤和红线。
- 证据边界：把 observed、inference、unknown、approval 用中文解释。
- 动态提示：统一改为可执行的下一步。

### 母婴内容洞察 `dist/deep-insight.html`

- 首屏先给决定：值得研究，但证据不足。
- 案例事实先列已知，再列未知。
- 故事线用具体动作描述，不用抽象分析词。
- 机制卡统一为“判断、替代解释、怎么验证”。
- 实验页只说明一个变量和判断方法。
- 结尾给出当前决定，不写泛化总结。

### 不改的内容

- JSON schema、字段名、文件名和下载路径。
- 技能 ID、工作流 ID、query 参数和浏览器存储 key。
- 数值、日期、媒体规格、来源 URL 和 reported 指标。
- `analysis-only`、`benchmark-only`、`awaiting_user_gate`、`confirmed`、`locked`、`unavailable`、`draft`、`pending`、`blocked`、`accepted`、`hold` 等机器状态。
- 案例 JSON 下载物。本轮只优化网页实际显示的文字，避免把页面润色和证据合同变更混在一起。

## 统一术语

| 原表达 | 页面统一表达 |
| --- | --- |
| route / 路由 | 选择主机制 |
| primary mechanism | 主机制 |
| evidence boundary | 能证明什么、不能证明什么 |
| bounded inference | 有依据、但有范围的推断 |
| unavailable | 没有数据（`unavailable`） |
| gate / preflight | 使用前检查 |
| workflow pack | 工作流 |
| artifact | 产物；机器字段仍保留 `artifact` |
| claim | 产品表述；机器字段仍保留 `claim` |
| benchmark | 参考案例；机器状态仍保留 `benchmark-*` |

1. 两个 HTML 页面中的用户可见文案都完成改写。
2. 每个主模块能在首句回答“这个模块有什么用”。
3. 同一概念不再频繁切换中英文近义词。
4. 说明性句子尽量控制在一个判断内；复杂条件拆成两句。
5. 状态码、数值、事实和证据边界与改写前一致。
6. 页面功能、浏览器本地草稿、下载和案例切换不受影响。
7. 桌面和移动端无新增横向溢出，控制台无 error 或 warn。
