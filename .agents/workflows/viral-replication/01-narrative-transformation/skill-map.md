# Skill map: narrative transformation

```text
viral-reference-intake
→ ReferenceBundle
→ viral-content-decomposition → DecompositionMap
→ viral-pattern-abstraction → PatternHypothesis
→ viral-narrative-transformation → ReplicationPlan
→ viral-fact-mapping → FactMap
→ viral-replication-contract → immutable ReplicationContract
→ narrative AdaptationPackage
→ factframe-script-storyboard → ScriptVersion → StoryboardVersion
→ viral-media-integrity → MediaIntegrityRecord
→ viral-experiment-evaluation → ReplicationFinding
→ factframe-readiness
```

共享 artifact 按上述顺序交接。`ReplicationPlan` 可在合同冻结前修订；`AdaptationPackage` 只封装既有 narrative adaptation，并接受本地 machine schema 验证，不产生 PostgreSQL/runtime persistence。任何结果都不代表 render、publish、rights、commercial 或 production approval。
